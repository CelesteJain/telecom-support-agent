# Setting up a New Router

Learn how to set up your new router to enjoy seamless internet connectivity.

1. **Power Off Existing Equipment**: Before connecting your new router, ensure that all devices and the old router are powered off.
2. **Connect Devices**: Plug the power adapter into your new router, then connect it to a power outlet. Connect the modem to the router via the Ethernet cable provided.
3. **Configure Settings**: Use a device connected to the router to navigate to the default IP address (usually 192.168.1.1 or 192.168.0.1) in your web browser to access the setup page. Follow on-screen instructions to complete the setup.
4. **Change Default Settings**: Update the Wi-Fi password and network name to secure your connection. Consider enabling parental controls or firewalls if needed.
5. **Test Your Connection**: Connect to the Wi-Fi network and test internet connectivity on different devices.

## When to Contact Support

- If you encounter issues with the setup process.
- If your router does not connect to the internet after following these steps.
- If you have any questions about security settings or network configurations.
